## Sobre mí

Soy **AnthoServ**, desarrollador de software especializado en el ecosistema Java. Trabajo con aplicaciones empresariales, integración de servicios y herramientas orientadas a mejorar la productividad y el mantenimiento del código.

Mi enfoque combina soluciones prácticas, código documentado y una arquitectura preparada para evolucionar. Actualmente también desarrollo extensiones para acercar a Visual Studio Code capacidades de navegación que los equipos Java esperan de un IDE completo.

> Java Software Developer focused on enterprise applications, integrations and developer tooling.

## Proyecto destacado

### [JSF EL Navigator](https://github.com/AnthoServ-Ship-it/jsf-el-navigator)

Extensión para Visual Studio Code que permite navegar con `Ctrl+clic` por expresiones EL de proyectos **JSF y PrimeFaces**:

- De XHTML al Managed Bean o bean CDI.
- Del controlador a servicios e implementaciones Java.
- Resolución de métodos, propiedades, herencia, interfaces y sobrecargas.
- Índice limitado al módulo actual para trabajar con proyectos Maven grandes.
- Diagnósticos, autocompletado, referencias y documentación integrada.
- Pruebas automatizadas y control de calidad con GitHub Actions.
